# 52 South booking backend

Google Apps Script source for the separately deployed booking endpoint. It logs each accepted request to a private Google Sheet, sends the restaurant/CC notification and a customer receipt, and records whether both mail calls completed.

The same endpoint accepts membership registrations when `form_type=membership`. It stores them in a private `Members` sheet, generates a unique member ID, and rejects duplicate identities using normalized email, the last nine mobile digits, or surname plus date of birth. Full dates of birth remain in the private sheet and are not included in notification emails.

Eligible members aged 21+ receive private Welcome Wheel links. Raw invitation tokens are emailed to members but only SHA-256 hashes are stored. The server enforces two spins per member per Monday–Sunday week in Australia/Hobart time, weighted prize selection, unique six-digit codes and 24-hour redemption. `Spin Access` and `Prize Wins` sheets are created automatically.

Member emails point to `https://52south.au/welcome-wheel/#TOKEN`. The fragment keeps the bearer token out of the website host request and optional analytics. That noindex wrapper embeds the Apps Script wheel; wheel responses use `XFrameOptionsMode.ALLOWALL` only because possession of the random 256-bit token is required for member access.

The staff redemption screen is available at the deployed web app URL with `?action=redeem`. It remains disabled until the script property `REWARDS_STAFF_PIN_HASH` is configured with the SHA-256 hash generated by the same `hashValue` function. Never store the plain staff PIN in source control.

The website form action must point to the deployed `/exec` URL. Keep the script deployment restricted to executing as the owner and accessible to anyone so customers do not need Google accounts.

Rollback: redeploy the previous Apps Script version and revert the matching website commit. The private Sheets are intentionally retained as audit logs; wheel invitations can be stopped immediately by changing their `Status` from `ACTIVE` or disabling the deployment.
